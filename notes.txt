station_pre_process.py:
- stations pre process appends a header to the ghcnd-stations.txt
- then filter out the non-us stations from the list and output a csv file.

weather_data_pre_processs.py
- extracts the Tmin, Tmax and keeps station ID, state and date
- generates a new collection of csv's of the weather data (2000-2023) 
- merges the weather data with the station data
- initally the weather didn't contain long, lat, state.
- using the us_stations.csv station ID, it matches with the weather data's station ID
- generate a newly proccessed weather data csv's containing geographical information. 


data_processing_pd.ipynb
- filters out missing tempreture data
- Filter to only stations starting with 'US'

data-merge.ipynb
- merges weather with bushfire data

weather-data-visualisation.ipynb:
- final processed data is used (non-bushfire)

bushfire-data-visualisation.ipynb:
- final bushfire contains only natural causes.

data_processing_merge:
- outputs a merged version of bushfire and weather data that includes all bushfire causes
- used only for visualisation purposes
- the process used to merge both datasets slightly differ compared to 'data-merge.ipynb'

data-cleanup: 
- Responsible for cleaning up the bushfire data
- Removes certains columns that aren't useful to our model
- Handles certain null values by removing them
- Implements better naming conventions
- Formats dates/time correctly

data-merge.ipynb:
- bushfire dataset is merged with the weather dataset based on how close it's geographical location to the weather dataset's longitude and latitude.
- removes any missing tempreture and elevation data.
- this file is computation heavy and is not recommended to run since it'll consume a lot of time.


machine-learning.ipynb:
- uses the merged_data.csv to train the model
- performs feature engineering, normalisation of values, and binning.
- splits the data 80% training...20% testing
- requires arguments like t_min, t_max, state and date in order to invoke 'predict_risk' function
